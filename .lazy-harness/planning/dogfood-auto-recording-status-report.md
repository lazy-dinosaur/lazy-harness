## Known operational issue

During this session the agent repeatedly used parallel wrappers for mutating or stateful operations. That caused duplicate commit/push/sync attempts and lock/race noise. This did not corrupt the repository, but it is a workflow problem.

Required operator discipline going forward:

```text
Do not use parallel/multi-tool wrappers for mutating operations.
Use single sequential calls for write/edit/apply_patch/git commit/git push/lazy-sync/todo updates.
Parallelize only read-only inspection when safe.
```
