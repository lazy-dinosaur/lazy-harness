🎯 Principle 0 — 존재 이유

사람도 AI 도 불완전하다. 그래서 상호 보완하며 진행한다.

이게 lazy-harness 의 존재 이유이자 모든 18 principle 의 메타 원칙.

tsq 가 잘 만든 정적 SSOT 도구라면, 우리는 사람-AI 상호 보완 라이프사이클 framework.

입력(figma/req/bug/api/log/regression) → adapter funnel → 5-finding 분석 → Conflict Resolution Protocol → human decision → DDD/SDD/BDD/TDD 자동 갱신 → code → traceability.
