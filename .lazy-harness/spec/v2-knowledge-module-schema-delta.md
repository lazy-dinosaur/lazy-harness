## Contract retained in the public copy

V2 remains a separate experimental review branch over the verified Main publication base. Registration does not complete work. Source-origin quote/semantic receipts do not constitute a human answer or subject-merge grant. Immutable runtime DB endpoint identity and atomic source root/host selection remain intact; source evidence is bounded to the caller's authorized root and exact manifest fingerprints.

The default brief writer receives the whole collected document; map/reduce remains opt-in. Unknown usage is unknown, not zero. Local E5-small and configured OpenRouter E5-large are distinct profiles; source publication does not select or activate either.

`portable_source.py` explicitly inventories the conditional Python runtime and 18 numbered V2 SQL assets. `templates.py` needs migration 0001 even without an installer. Archive digests and Python AST checks are shape/source evidence, not live JS/SQL execution or PostgreSQL correctness.

The public diagnostic `portable_probe.probe(host, vector=False, *, query=None)` rejects absent explicit configuration before importing configuration-backed dependencies. Vector mode additionally requires a nonblank caller query; a real product query is not a distributed fixture. This requires separate live-diagnostic approval and is not a publication test.

Private per-case diagnostic queries/identifiers were omitted from the public `lineage_row_provider.py` copy. They are not generic lineage authority. The root/namespace/selector/history/CAS and receipt predicates remain the source implementation; no real ledger, receipt, source bundle or vector is included.

V2 maintenance closure includes `cleanup.run(..., state_dir=STATE)`, `reopen_duplicates.classify`, `backfill_structure.{plan,apply}` and `merge_guard.{code_missing,clause_missing}`, plus the conditional `fragmenter/check_fragments.py` parser. The original V2 signatures, host lock, preview/explicit-apply and revision-CAS mechanics remain intact. `PostgresLineageRowProvider` now requires an explicit keyword namespace rather than a private deployment default; no selected caller depended on the old default. Test row shapes retain the alias/storage mismatch protections with synthetic IDs and aliases.

The inherited `scale-03/measure` publication is **not** the original paid/data orchestration. Both public `main` entry points require an explicit synthetic fixture and otherwise fail closed before configuration/data/model access. `run_mapreduce` retains the 70-question/three-run estimate and resume mechanics for injected fixture writers, records only labeled synthetic results and stops on unknown/nonfinite/negative costs or an ambiguous failure, without inventing charges or automatic reconciliation. `judge_measure` retains chunk aggregation and original/corrected threshold mapping with an explicit synthetic verdict callback; it has no live HTTP/auth path. Fixture callbacks are not a Runtime provider or business approval. The runtime brief writer and real ownership/price/hold rules are not changed by these adapters.

The existing Pi extension is copied as inactive source, with no API migration or runtime attachment. Main's SDK0.85.1 checks do not certify managed SDK1.3. G16 closure and its additional SQL/native/financial boundaries remain a separate publication phase.
