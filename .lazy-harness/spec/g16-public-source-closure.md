## Bounded public contract

G16 evolves the experimental runtime over the V2 public-safe foundation: domain-scoped identities/aliases/parents, typed write and rejected-input validation receipts, provisional read-only subject inspection, model-bound embedding cache/admission and top-K candidate routing, unit-first writing/grounding and existing dynamic ModelRuntime hosts. The default brief profile is G16's `openai/gpt-6-luna:medium`; the separate historical V2 branch is not blanket-replaced. Main/Fabric and its SDK0.85.1 baseline are not migrated or activated.

`portable_source.REPOSITORY_ALLOWLIST` is the explicit repository-shaped package: module source under `experiments/v2-knowledge-module-runner-01/` plus bounded Native source/tests under `experiments/v2-native-minlive/`. Module-only packaging remains distinct. Digests, member equality, symlink and size checks apply to both profiles. SQL 0001 is also a runtime template seed dependency. The loader selects 0001–0023 in order, excluding alternative apply forms; 0023 absence raises typed `ValidationReceiptMigrationRequired`, not an automatic migration. Generic SQL seed/backfill logic is source, not a database export or permission to execute it.

`write_confirmed(plan, home, approval)` keeps exact plan digest, isolated home containment, both home/state plan identities and conflicting-catalog refusal. Its ten neutral fixture areas and `confirmed_by_user` field explicitly describe only synthetic confirmation. Non-synthetic plans are refused by this writer. `prepare.inputs` requires an explicit distributed synthetic manifest; private inventory/calibration/result fingerprints are removed and baseline quality is explicitly unavailable. No original prepared source/plan hashes, private business catalog, before manifest, ledger, raw output, caches or credentials are included. Synthetic carry values preserve finite/exact carry checking but are not original balances or new cash authority.

Actual `scale-04/jev_failure.py` is included as received-error and matched-receipt checking source. HTTP status or self-reported zero usage is not proof of free execution. Source availability does not establish approved financial runtime provenance: Paid HTTP/model/entry, generation lookup, resolution/release, default host subprocess, production construction, Docker and non-prepare pipeline entry stop before effects. Unknown reservations are not automatically refunded or replayed. Native's independent externally attested Trust/quote/history/selected-admission boundaries remain; the public caller cannot provision a real lease or promote returned values into authority.

Native Python paths are repository-bound, bridge MJS remains a sibling, and both dynamic JS hosts are file-relative and realpath-checked. Existing external SDK/auth capabilities remain explicit pinned inputs, not bundled runtimes or automatic discovery approval. No source publication creates semantic/live/financial acceptance.
